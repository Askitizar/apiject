# 🍳 Meal Explorer — Кулинарный справочник

Веб-приложение для поиска рецептов блюд со всего мира, просмотра списка ингредиентов с пропорциями и сохранения понравившихся блюд в личную кулинарную книгу.

## Целевая аудитория и задачи
- **Для кого:** люди, которые ищут идеи для готовки, изучают кухни разных стран и хотят сохранять проверенные рецепты под рукой.
- **Решаемая задача:** быстрый поиск рецепта по названию, фильтрация по категориям блюд, просмотр точного списка ингредиентов и пошаговой инструкции приготовления.

## Технологический стек
- **HTML5 / CSS3** (семантическая верстка, CSS Grid, модальное окно `<dialog>`, адаптивный дизайн).
- **JavaScript (ES6+ Modules)** — модульная архитектура (`api.js`, `ui.js`, `main.js`) без сторонних зависимостей.
- **Fetch API + async/await** — асинхронные сетевые запросы и обработка ошибок.
- **LocalStorage** — сохранение списка избранных рецептов между перезагрузками страницы.

## Используемый API
- **Название:** TheMealDB API (v1)
- **Документация:** https://www.themealdb.com/api.php
- **Авторизация:** используется публичный тестовый ключ `1` в пути URL (секретные ключи не требуются).
- **Используемый эндпоинт:**
  - `GET https://www.themealdb.com/api/json/v1/1/search.php?s={query}` — получение списка рецептов или поиск блюд по названию.
- **Ключевые поля ответа:** `idMeal`, `strMeal`, `strCategory`, `strArea`, `strMealThumb`, `strInstructions`, `strIngredient1..20`, `strMeasure1..20`.

## Инструкция по запуску
1. **Через VS Code:** Откройте папку проекта в VS Code и запустите расширение **Live Server** (кнопка **Go Live**).
2. **Через терминал (Node.js):** Выполните `npx serve .` в папке проекта и откройте `http://localhost:3000`.
